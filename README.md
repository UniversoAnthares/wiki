# Anthares Wiki

Este repositório é o ponto versionado para documentação, contratos e decisões que precisam acompanhar o ecossistema Anthares. No estado atual ele ainda é um **placeholder**: não há páginas, código, workflows ou assets publicados além deste README.

## Como usar

- Adicione cada página documental como Markdown versionado, com um título claro e links relativos verificáveis.
- Registre decisões de arquitetura e contratos estáveis aqui quando eles não pertencerem a um repositório de implementação específico.
- Não coloque neste repositório cookies, tokens, senhas, dados de sessão ou conteúdo privado.
- Antes de publicar conteúdo real, adicione validação de Markdown e links no CI.

## Estado atual

Não há testes aplicáveis enquanto o repositório contiver apenas este placeholder. Também não há logo ou outro asset visual versionado; se a plataforma não fornecer a identidade visual externamente, o asset canônico deverá ser definido junto com a primeira página pública, sem inventar uma marca neste placeholder.
